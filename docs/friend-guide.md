# 練習室の自動予約：はじめての手順

リザベーションエンジンの練習室を、予約が始まる時刻に自動で予約するしくみです。
スマホから予定を登録すると、管理者のPCで動いている「予約係」が、**あなたのログインIDで**予約します。

## 先に知っておいてほしいこと

- あなたの予約サイトのログインIDとパスワードは、管理者のPCの「資格情報マネージャー」に保存されます。画面には表示されません。
- 予約は全自動です。確認画面で止まらずに予約を送信するので、**予定の日時・部屋をよく確かめてから**登録してください。
- 管理者のPCが止まっていると、予約されません。大事な予約は、予約可能日時の後に予約サイトでも確かめてください。
- 1つの予定につき、予約を試すのは1回だけです。部屋が埋まっていたら、別の日時で登録し直してください。
- アカウントとアドレスは自分だけで使い、ほかの人に教えないでください。

---

## 1. 予定登録の画面を開く

1. 管理者から教えてもらったアドレス（`https://〜.ts.net`）を、スマホのブラウザで開きます。アプリを入れる必要はありません。
2. 管理者から教えてもらった**ユーザー名**と**最初のパスワード**でログインします（コピーして貼り付けてかまいません）。
3. 「ユーザー名とパスワードを決めてください」と出ます。
   - ユーザー名は、そのままでも、好きなもの（英小文字・数字・_・- の2〜20文字）に変えてもかまいません。変えたら、次からは新しいユーザー名でログインします。
   - パスワードは、自分だけが知っているものに変えます。iPhone などが「強力なパスワード」を提案したら、それを使うと次から自動で入ります。
   - 8文字以上
   - 数字だけ・ユーザー名を含む・「password」のようなよく使われる言葉を含むものは使えません
   - **予約サイトのパスワードとは別のもの**にしてください
4. 「はじめに」として、注意事項と使い方が5ページで表示されます。「次へ」で読み進め、最後のページで「理解しました」にチェックを入れて「使い始める」を押します。
   あとから見直すときは、画面上部の「使い方を見る」を押します。

> パスワードを5回続けて間違えると、15分ロックされます。忘れたときは管理者に設定し直してもらってください。
> 30分操作しないと、自動でログアウトします。

## 2. 最初の設定

### 予約サイトのログイン情報（必須）

1. 「**予約サイトのログイン情報**」を開きます。
2. リザベーションエンジンのログインIDとパスワードを入れて「保存する」を押します。
3. 保存する前に、その場で予約サイトにログインできるかを確かめます（20秒ほどかかることがあります）。
   - 「予約サイトにログインできませんでした」と出たら保存されていません。ログインIDとパスワードを確かめて入れ直してください。
   - 3回続けてログインできないと、15分間は確かめられなくなります（予約サイトのアカウントが止められるのを防ぐためです）。
4. 保存できたら、予約係があなたに見える部屋はどれかを確かめます（数分かかります）。画面を再読み込みして、見出しが「（確認済み：使える部屋 〇室）」になれば完了です。
   予約サイトは、あなたのコースで使える部屋だけを見せます。このアプリでも、**あなたに見える部屋だけ**を選べます（管楽器コースの部屋、ピアノコースの部屋など）。

### お知らせメール（任意）

予約係に任せた予定の結果（予約完了・予約できなかった）を、メールで受け取れます。

1. 「**お知らせメール**」を開き、メールアドレスを入れて「確認番号を送る」を押します。
2. 届いたメールの6桁の確認番号を入れて「登録する」を押します（30分以内。届かないときは迷惑メールのフォルダも見てください）。
3. やめるときは「お知らせメールの登録を取り消す」を押します。

### 注意事項の承認（Medium・Large の部屋を使う人だけ）

E215・E311・E312・E313・E412・E414・E415・E432・E441・E442・E451・E452 は、予約するときに「複数人利用 優先のお願い」の確認が必須の部屋です。これらの部屋を使う場合は：

1. 「**注意事項の承認**」を開き、文面を読みます。
2. 「上の注意事項を読み、…承認します」にチェックを入れて「承認する」を押します。

これらの部屋では、**同時利用者の学籍番号**が必須で、利用は**2時間まで**です。一緒に使う人には、学籍番号を予約に使うことを伝えておいてください。

### 担当教員名（E313 を使う人だけ）

「自動予約の設定（使う部屋）」の「担当教員名」に、主科の担当教員名を入れます（該当しない場合は `AA`）。

### 使う部屋

1. 「**自動予約の設定（使う部屋）**」を開きます。
2. 「ピアノで絞り込む」で、グランド・アップライト・ピアノなし から使いたい種類だけを選ぶと、その部屋だけが一覧に出ます（部屋の名前の後ろにもピアノの種類が出ます）。
3. 「個人練習で使う部屋」と「アンサンブルで使う部屋」を、**試したい順に**選びます。1回の予約で、上から最大5室を順に試します。
4. 「設定を保存」を押します。

## 3. 予定を登録して、予約係に任せる

1. 「**1. 予定を入力**」で、利用日・開始時刻・利用時間・練習の種類を選びます。
   同時利用者が必要な部屋が含まれるときは、学籍番号を1行に1人ずつ入れます。
2. 「**2. 確認**」で、次を確かめます。
   - 利用時間
   - 予約可能になる日時（利用終了の7日前）
   - この日の合計（**1日180分**を超える予定は任せられません）
   - 試す部屋（この順）
3. 「**予定として登録する**」を押します。
4. 「**3. 登録済みの予定**」で、その予定の「**予約係に任せる**」を押します。
   「⏳ 予約係に任せています」と出れば完了です。予約可能日時になると、自動で予約されます。

### 大学の予約ルール

- 利用できるのは **7:00〜22:00** です。
- 1日は最大 **3時間・4回まで** です。
- 30分おきに予約と空きを交互に作る使い方は、規程より長く使う悪質な利用とみなされることがあります。続けて使うときは、1つの予定にまとめてください。
- 閉館日・短縮開館日も予約できてしまいます。開館時間を確かめてから登録してください。
- 予定が変わったら、**すぐにキャンセル**してください（予約サイトの「予約内容」から。予約係に任せている予定は「任せるのをやめる」）。

## 4. 結果を確かめる

予約可能日時を過ぎたら、画面を開き直して（再読み込みして）、予定を確かめます。

| 表示 | 意味 | すること |
|---|---|---|
| ✅ 予約完了（自動・E〇〇〇） | 予約できました | 念のため予約サイトの「予約内容」でも確かめる |
| 前回の自動予約：空きなし | 試した部屋がすべて埋まっていました | 別の日時・部屋で登録し直す |
| 前回の自動予約：予約できなかった：…確認画面に登録ボタンなし（…） | 予約サイトが受け付けませんでした。かっこの中が予約サイトの表示です | 下の「予約できなかったとき」を見る |
| 前回の自動予約：…画面が開かなかった | 予約サイトが混んでいた等で、画面が開きませんでした | 別の日時で登録し直す |
| 前回の自動予約：中止… | 途中で止まりました。理由が書いてあります | 困ったら管理者に伝える |

予約係が試すのは、1つの予定につき1回だけです。「予約係に任せる」を押し直すと、もう一度試します。**押し直す前に、上の理由を確かめてください。**

### 予約できなかったとき

- **「申し込み数が上限」と出た**：あなたの予約サイトのアカウントが、同時に持てる予約の数の上限に達しています。どの部屋でも予約できません。予約サイトの「予約内容」で使わない予約を取り消すか、予約を使い終わるのを待ってから、もう一度任せてください。
- **そのほかの理由**：かっこの中の予約サイトの表示を読み、分からなければ管理者に伝えてください。

## よくある操作

| したいこと | 操作 |
|---|---|
| 任せた予定をやめる | その予定の「任せるのをやめる」（任せている間は削除できません） |
| 自分で予約サイトから予約した | その予定の「手動で予約した → 完了にする」 |
| 予約サイトのパスワードを変えた | 「予約サイトのログイン情報」で保存し直す |
| ユーザー名を変える | 「この画面のユーザー名を変える」で、新しいユーザー名と今のパスワードを入れる（予定や設定はそのまま引き継がれます） |
| ログアウトする | 画面上部の「ログアウト」 |
| パスワードを忘れた | 管理者に設定し直してもらう |
