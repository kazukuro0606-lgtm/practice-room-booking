# 管理者向け：友達に使ってもらう手順

友達1人ごとに、次の1〜4を行います。まず1人に試してもらい、つまずいたところを直してから、ほかの人に広げてください。

## 始める前に（友達ごとに一度）

友達本人に、次のことを伝えて同意をもらってください。

- 予約サイトのログインIDとパスワードを、あなたのPCの「資格情報マネージャー」に保存します。画面には表示されず、管理者にも画面からは見えませんが、PCそのものを操作できる人なら技術的には取り出せます。
- 予定登録の画面はインターネットに公開しています（Tailscale Funnel）。URLを知った人はログイン画面まで開けます（パスワードの基準とログイン失敗の制限で守っています）。
- 予約は、あなたのPCの予約係が、友達本人のログインIDで行います。PCが止まっていると予約されません。
- 同時利用者の学籍番号は、あなたのPCにだけ保存されます。一緒に使う人に、予約に使うことを伝えてもらってください。
- 同じ時間・同じ部屋をほかのメンバーと狙うと、先に処理された人が取ります。メンバーどうしで決め方を話しておいてください。

## 1. アカウントを作る

1. 予定登録の画面に管理者でログインします。
2. 「アカウントの管理（管理者だけに表示）」を開きます。
3. ユーザー名（英小文字・数字・_・- の2〜20文字。例：`sato`）を入れて「作る」を押します。
4. 表示された**ユーザー名と最初のパスワード**を控えます（この表示は一度だけです）。最初のパスワードは自動で作られ、友達は最初のログインで自分のパスワードに変えるよう求められます。

## 2. 友達に伝える

次の3つを、**直接会って**、または友達だけが見られる方法で伝えます（グループのチャットには書かない）。

- 予定登録の画面のアドレス（`tailscale funnel status` で確認できる `https://〜.ts.net`）
- ユーザー名
- 最初のパスワード

あわせて、友達向けの手順書（`docs/friend-guide.md`）を送ります。友達は Tailscale のアプリを入れる必要はありません。

## 3. 公開が続いているか確かめる

PCを再起動した後なども、`tailscale funnel status` で公開が続いているか確かめられます。公開をやめるときは `tailscale funnel --https=443 off`。

## 4. アカウントの確認結果を見る

友達が予約サイトのログイン情報を保存すると、予約係が自動で、ログインできるか・その人に見える部屋を確かめます。
画面の「予約サイトのアカウントの確認結果（管理者だけに表示）」で、全員の結果を見られます。

- 「アプリに未登録の部屋」（例：ピアノコースの E311）が出たら、その下の調査結果を Claude に送ってください。部屋を登録して使えるようにします。

## 5. 最初の予約を見守る

- 友達が最初の予定を「予約係に任せる」にしたら、予約可能日時の後に、その予定の「前回の自動予約」の記録を一緒に確認します。
- うまくいかなかったときは、予約係のPCの `data\logs\予定番号.log` に、どこで止まったかが残っています（ログイン情報は書かれていません）。

## 毎日の使い方（管理者のPC）

PowerShell で、このフォルダ（`cd $HOME\practice-room-booking`）に移ってから実行します。

| したいこと | すること |
|---|---|
| 予約係と画面を起動する | `powershell -ExecutionPolicy Bypass -File .\start.ps1`（サインイン時の自動起動を登録していれば不要） |
| 止める | 予約係と画面の2つのウィンドウで Ctrl + C。ウィンドウを閉じても止まります |
| 最新版にする | 止めてから `git pull`。**2分待ってから** `start.ps1`（すぐ起動すると「予約係はすでに動いています」と出ます） |
| 公開の状態とアドレスを確かめる | `tailscale funnel status` |
| 公開をやめる・再開する | `tailscale funnel --https=443 off` ／ `tailscale funnel --bg 8501` |
| 予約係の記録を見る | `Get-ChildItem data\logs \| Sort-Object LastWriteTime` で新しいファイルを探し、`Get-Content data\logs\ファイル名 -Encoding UTF8` |

- `tailscale` が見つからないと言われたら、`& "C:\Program Files\Tailscale\tailscale.exe" funnel status` のように場所を付けて実行します。
- `Port 8501 is not available` と出たら、画面はすでに動いています。ブラウザで `http://localhost:8501` を開いてください。
- 予約係のウィンドウを閉じると予約係も止まります。最小化はかまいません。PC はスリープさせないでください。

## 困ったとき

| こんなとき | すること |
|---|---|
| 友達がパスワードを忘れた・ロックされた | 「アカウントの管理」でアカウントを選び、「パスワードを設定し直す」（新しいパスワードが表示され、ロックも解除されます） |
| 友達が使うのをやめる | 「アカウントの管理」で削除（その人の予定・設定・予約サイトのログイン情報も消えます） |
| 予定に「申し込み数が上限」と記録された | その人の予約サイトのアカウントが、同時に持てる予約の数の上限です。予約を使い終わるか取り消すまで、どの部屋も予約できません |
| 画面に「予約係が動いていません」 | PCで `start.ps1` を実行する（サインイン時の自動起動を登録していれば、PCを再起動してサインインする） |
| 管理者のパスワードを忘れた | PCで `python app_auth.py reset 管理者のユーザー名` |
