# 練習室予約の予定登録と自動予約

Windows の PC内（localhost）だけで動く、自分用の練習室予約ツールです（2026-10 に ensemble-scheduler リポジトリから移動）。

- 予定登録の画面（`app.py`）で予定を登録して「予約係に任せる」と、PCで動く予約係（`scheduler.py`）が予約可能日時に自動で予約します（`auto_reserve.py`）。
- 予約先はリザベーションエンジン（`www4.revn.jp/senzoku`）。自動操作で予約してよいことは、利用者本人が管理担当に確認済み。
- ログインID・パスワードは Windows の資格情報マネージャーに保存します（ファイル・Gitには残りません）。
- E452 の注意事項は、本人が承認した文面（`notices.py`）と同じときだけ自動で同意します。
- 「予定（未予約）」と「予約完了」を分けて表示します。
- 登録した予定・同時利用者・設定は `data/` に保存されます（Gitには追加されません）。

## ルール（`booking_rules.py`）

- タイムゾーンは Asia/Tokyo
- 予約可能日時＝利用終了日時の7日前（例：2026-10-28 15:00〜16:00 → 2026-10-21 16:00 から）
- 同じ利用日の「既存予約＋希望予約」が180分を超えたら警告
- 使う部屋は、人ごとに練習の種類（個人練習／アンサンブル）別に、試したい順に設定する（`rooms.py`）。初期値は、個人練習が E312・E313 を除く3階の部屋、アンサンブルが E452
- 利用時間は 30分〜3時間（30分刻み）

## 初回の準備（Windows / PowerShell）

このリポジトリのフォルダで次を実行します。

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

`Activate.ps1` が「スクリプトの実行が無効」で止まる場合は、次の1行を実行してからやり直してください（今開いているPowerShellだけに効きます）。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

## 起動

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。開かない場合はアドレスを直接入力してください。
`.streamlit/config.toml` で待ち受け先を `localhost` に限定しているので、他の端末からは接続できません。

## 停止

起動したPowerShellの画面で **Ctrl + C** を押します。ブラウザのタブを閉じただけでは止まりません。

## テスト

```powershell
python -m unittest -v
```

## 段階2-1：予約ページをEdgeで開く（ログイン・予約送信はしない）

`local_settings.example.toml` をコピーして `local_settings.toml` を作り、`url` に予約ページのアドレスを書きます。
学籍番号・パスワードは書きません。`local_settings.toml` はGitに追加されません。

```powershell
python -m pip install -r requirements.txt
Copy-Item local_settings.example.toml local_settings.toml
notepad local_settings.toml
python open_site.py
```

Edgeが開き、予約ページが表示されます。Edgeのウィンドウを閉じると終了します。

## 段階2-2：自動ログイン（予約の入力・送信はしない）

ログインIDとパスワードは Windows の資格情報マネージャーに保存します（ファイル・Gitには残りません）。

```powershell
python -m pip install -r requirements.txt
python credentials.py save
python auto_login.py
```

- `credentials.py save`：ログインIDとパスワードを入力して保存します。パスワードは入力しても表示されません。
- `auto_login.py`：Edgeを開いて自動でログインします。ログイン情報は `www4.revn.jp` のページにだけ入力します。
- 保存したログイン情報を消すとき：`python credentials.py delete`

## 段階2-3の準備：予約画面の構造を調べる

```powershell
python inspect_page.py
```

自動でログインした後、予約の画面を1つずつ進め、画面ごとにPowerShellで Enter を押すと記録します。終わるときは `q` を入力して Enter。
**最後の「予約する」「申し込む」などのボタンは押さないでください。**
入力欄・ボタン・リンクの名前だけを `inspect_result.txt`（Git対象外）に保存します。入力された中身・Cookie は書き出さず、URLの秘密らしい値は `***` で伏せます。

## 段階2-3：予約内容を入力し、確認画面で止める（練習モード）

```powershell
python reserve_dryrun.py --room E320 --date 2026-10-28 --start 09:30 --minutes 60
```

- `--room`：部屋の名前（例：E320、E452。一覧と番号は `rooms.py`。まだ確かめていない部屋の画面を調べるのにも使えます）
- `--use-type`：利用区分の表示名（省略すると「個人練習」）
- E452（TB）は利用時間が2時間まで。実行すると同時利用者の学籍番号を1人ずつ聞かれます（保存しません）。
  注意事項「複数人利用 優先のお願い」は、2026-10-21 に承認した文面（`notices.py`）と同じときだけ自動で確認にチェックします。文面が変わっていたら同意せずに止まります。
- `--minutes`：30・60・90・120・150・180 のいずれか
- 自動でログインし、利用区分と利用時間を入力して確認画面まで進みます。
- **確認画面の「登録」ボタンは押しません**（このプログラムには押す処理がありません）。Edgeを閉じると終了します。

## 部屋の番号（event_id）の一覧を調べる

```powershell
python list_rooms.py
```

自動でログインし、予約状況の画面にある部屋の名前と番号を表示します（`rooms_result.txt` にも保存。Git対象外）。

## 段階2-4：予約を送信する

```powershell
python auto_reserve.py --date 2026-10-26 --start 16:30 --minutes 90
```

- `--practice`：`個人練習`（初期値）か `アンサンブル`。`--user` を付けるとその人の部屋の設定を、付けないと初期値の部屋を使います
- 予約可能日時より前に起動すると、その3分前にログインし、時刻（＋2秒）まで待ってから予約します。待っている間はPCをつけたままにしてください。
- 候補の部屋を順に最大5室試し、確認画面まで進めた部屋で「登録」を**1回だけ**押します。押した後は別の部屋を試しません。
- `--yes` を付けないと、「登録」を押す前に PowerShell で `y` の入力を求めます。全自動にするときだけ `--yes` を付けます。

## 予約係（scheduler.py）と予定登録の画面を動かす

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

予約係（`scheduler.py`）と予定登録の画面（`app.py`）が、それぞれ新しいウィンドウで起動します。どちらも閉じずに、PCをスリープさせないでください。
個別に起動するときは `python scheduler.py` と `streamlit run app.py`。

- 「3. 登録済みの予定」の **「予約係に任せる」** を押すと、予約係が予約可能日時の10分前に自動予約を始め（`auto_reserve.py --plan-id 〜 --unattended`）、時刻になったら予約します。Edgeは画面に出しません。
- 予約係の予約は全自動（確認画面で止まらない）です。1つの予定につき1回だけ試し、結果は予定の「前回の自動予約」に記録されます。
- 「任せるのをやめる」で取り消せます。実行中でも、予約を送る直前に取り消しを確かめて止まります。任せている間は予定を削除できません。
- 実行のようすは `data/logs/予定番号.log` に残ります（ログイン情報は書きません）。
- 予約係が止まっているときは、画面に「予約係が動いていません」と表示されます。
- 予約が完了すると、その予定が「予約完了（自動・E3xx）」に変わります（画面を再読み込みすると反映されます）。
- 1日の合計＝「アプリの外で取った予約時間（手入力）」＋「このアプリで予約完了の予定」＋「その予定」。180分を超える予定は自動予約できません。
- 「手動で予約した → 完了にする」で、自分で予約した予定を予約完了にできます。

## 自動予約の設定と記録（予定登録の画面）

- 画面上部の「自動予約の設定（使う部屋）」で、練習の種類ごとに使う部屋を**試したい順に**選んで「設定を保存」を押します（`data/settings/ユーザー名.json` に保存。Git対象外）。1回の予約で上から最大5室を試します。
  - 選べるのは、予約画面の作りを確かめた部屋（2階、E312・E313 を除く3階、E452）だけです。楽器の部屋（E412・E432・E441・E442・E451）と E312・E313 は、画面を調べてから追加します。
  - 予定を登録すると、そのときの設定から「試す部屋」が決まり、予定に保存されます（後で設定を変えても、登録済みの予定の部屋は変わりません）。
  - 利用時間がその部屋の上限（E452 は2時間）を超えるときは、その部屋を外して試します。E452 を含む予定では、同時利用者の入力が必要です。
- 自動予約を実行すると、予定の下に「前回の自動予約」として、実行時刻・結果・埋まっていた部屋が表示されます。注意事項の文面が変わっていた、ログインできなかった等で途中で止まった場合も、その理由が記録されます。

## スマホから使う（Tailscale Serve）

予定登録の画面は PC の localhost だけで動かしたまま、Tailscale でつないだ自分の機器からだけ https で開けるようにします。インターネットには公開しません。

1. 管理者のアカウントを作ります（パスワードは8文字以上。保存されるのはハッシュだけで、`data/users.json` に入ります）。
   ```powershell
   python app_auth.py add-admin ユーザー名
   ```
   管理者が初めてログインすると、それまでの予定・設定・予約サイトのログイン情報が、管理者のものとして引き継がれます。
2. PC とスマホに Tailscale を入れ、同じアカウントでログインします。
3. PC で予定登録の画面を起動したまま、別の PowerShell で次を実行します（PC を再起動しても続きます）。
   ```powershell
   tailscale serve --bg 8501
   ```
   表示された `https://〜.ts.net` をスマホのブラウザで開き、パスワードを入力します。
4. 公開をやめるとき：`tailscale serve reset`

注意：予約は PC の予約係が行います。予約の時刻に、PC がサインインした状態で、スリープしておらず、予約係が動いている必要があります。

## 友達も使う（人ごとのアカウント）

- 管理者が画面の「アカウントの管理」で友達のアカウント（ユーザー名と最初のパスワード）を作り、本人に伝えます。
- 友達はログインしたら、最初に「予約サイトのログイン情報」に自分のログインIDとパスワードを保存します。
  資格情報マネージャーに人ごとに分けて保存され（`practice-room-reservation-engine:ユーザー名`）、画面には表示されません。
- 予定・設定・1日180分の確認は人ごとに分かれ、自分の分だけが表示されます。自動予約は、予定を登録した本人のログイン情報で行います。
- 予約係の予約は、全員分とも全自動（確認なし）です。
- 友達の機器からつなぐには、Tailscale の管理画面で、この PC を友達に共有（Share）します。
- 管理者はアカウントのパスワードの設定し直しと削除ができます。削除すると、その人の予定・設定・予約サイトのログイン情報も消えます。
- 自分のパスワードは「この画面のパスワードを変える」で変更できます。管理者のパスワードを忘れたときは、PC で `python app_auth.py reset ユーザー名`。
